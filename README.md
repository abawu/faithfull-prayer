# Rooted Prayer Journal

A pixel-art devotional journal for Befekadu.

## Open locally

Open [index.html](index.html) in a browser, or serve the project with any static web server. The complete app lives in `dist/index.html` and includes:

- Home message and “Let us pray” flow
- Finance, relationships, work, spirituality, and custom prayer spaces
- Current situation, faith confession, and prayer fields
- Date-based private browser saving
- Additional titled prayers for each day
